# AI data-center contract pack

These are negotiation templates, not executed agreements or legal/tax advice.
Complete the bracketed fields and obtain Japanese counsel, tax-accountant,
facility-engineer and information-security review before signature.

| Document | Use | Required reviewer |
|---|---|---|
| `01-master-services-agreement.md` | customer/operator base terms | legal |
| `02-equipment-purchase-order.md` | GPU equipment procurement | procurement + legal |
| `03-hosting-operations-schedule.md` | colocation and operations scope | facility + legal |
| `04-service-level-schedule.md` | service levels and service credits | operations + legal |
| `05-data-security-schedule.md` | tenant data/security allocation | security + privacy |
| `06-acceptance-certificate.md` | installation and commissioning acceptance | facility + customer |

No document may state that tax treatment, utilisation, resale value or return
is guaranteed. External-send and signature are approval-gated effects.
